# Contact Book System

A simple Contact Book System built using Python and file handling.

## Features

* Add Contact
* View Contacts
* Search Contact
* Update Contact Number
* Delete Contact

## Technologies Used

* Python OOP
* File Handling
* Lists
* Loops and Conditions
* Data Management

## Project Structure

Each contact record contains:

contact_id, contact_name, phone_number

Example:

101,John,9876543210

102,Alice,9123456780
